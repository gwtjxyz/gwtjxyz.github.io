## [Vulkan Rendering Engine (WIP)](https://github.com/gwtjxyz/VulkanRenderEngine)

### Written in: C++ (VulkanHpp, flecs, ImGui, fastgltf, CMake)

Under active development; project to learn a modern graphics API and various rendering techniques while trying to use best modern practices when applicable.
Currently supports OBJ and GLTF file formats, basic lighting models, HLSL shaders, bindless rendering, shader hot reloading,
basic particle compute display, and adding/removing arbitrary amounts of lights to the scene. Built to run cross-platform
on Windows and Mac, with Mac's hardware constraints in mind.

![](assets/vulkan.png)

## [AudioSwitcher](https://github.com/gwtjxyz/AudioSwitcher)

### Written in: C++ (Win32, Visual Studio)

Simple, minimal and lightweight Win32 application that creates a tray icon you can use to switch your audio devices in one click
and saves you the hassle of having to use Windows 11's slow and clunky built-in UI for it or worry about not hearing your
friends over voice chat because something got stuck as a selected communication device. Bonus feature of a one-click
navigation to the control panel version of sound settings because Win11 puts way too much effort into hiding it from you.

![](assets/audioswitcher.png)
